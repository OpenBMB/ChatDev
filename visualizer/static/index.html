Google Drive 연결

Not Connected

Google API 키 직접 입력
3분 실전 연동 가이드
  1. Google Cloud Console 접속 → 새 프로젝트 생성
  2. Google Drive API 활성화 → OAuth 동의 화면 설정 (외부/테스트 사용자)
  3. 사용자 인증 정보 → OAuth 클라이언트 ID 만들기 (웹 애플리케이션)
  4. 승인된 리디렉션 URI에 아래 주소를 등록:
    http://127.0.0.1:8000/api/gdrive/callback
  5. 발급된 Client ID와 Client Secret을 프로젝트 루트의 .env 파일에 저장:
    GOOGLE_CLIENT_ID=발급된_클라이언트_ID.apps.googleusercontent.com
    GOOGLE_CLIENT_SECRET=발급된_시크릿_키
    GOOGLE_REDIRECT_URI=http://127.0.0.1:8000/api/gdrive/callback

💡 .env 파일 저장 후 서버를 재시작하면 자동으로 인식됩니다. 키가 없으면 Sandbox 모드가 자동 활성화됩니다.
